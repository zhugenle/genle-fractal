# 自由迭代节点首版交付

日期：2026-10-14。分支：`codex/composable-formula-nodes`。本地入口：`http://127.0.0.1:4186/composer.html`。未发布；线上 v16 保持现状。

## 用户确认后的范围

用户进一步明确：提取 UBER BULB、SPIKED CUBE 内部功能成为节点，自由连接以生成新公式。因此本批次直接实现规划中的迭代算子主线，而不是以两个完整距离场的并集替代混合迭代。

当前为单一显式循环、OrbitState 端口的 DAG；连线决定每轮运算顺序。支持分叉与双路状态混合。输入/输出节点各一个，反馈通过历史提交和常量反馈表达，拒绝直接连线成环。

## 已实现

- 22 种节点：状态输入、距离/循环输出，以及 20 类 UBER、Cube 和通用算子。
- UBER：径向重映射、球坐标幂、常量与历史混合、历史提交、常量反馈、正弦轴调制、逆柱坐标、分式正弦乘法。
- Cube：绝对值折叠、三轴排序、尖刺分段折叠、脊线夹取、轴向偏移折叠、IFS 缩放与常量注入。
- 公共：迭代旋转、平面扭转、向量偏移、两路混合、逃逸检查、轨道采样；输入包含世界变换、物体旋转、Julia/常量规范化。
- 三个参考图：UBER 算子还原、Cube 算子还原、折叠 × 球面幂。前两者保留各自的退出位置、历史顺序、轨道采样及距离收束语义。
- 添加、复制、删除算子；点击或拖动接线；检查器选择上游；撤销重做；节点拖动、画布平移缩放、全图与定位；本地恢复。
- 公开参数绑定；导出/导入节点图 JSON 和本项目公式包；工作室加载公式包、修改公开参数、导出包含新值的完整公式。
- 真正生成 GLSL；参数作为 uniform，参数/布局更新不改变 shader 数学源码。线性路径复用状态，分叉保留快照，减少 GPU 编译开销。
- 编译失败保留最后成功程序；替换程序释放旧图 GPU 对象；新旧异步请求以 revision 防止旧结果覆盖新图。
- 不允许自定义图覆盖旧格式的本地预设。自定义图使用公式包保存，普通公式原预设继续使用原路径。

## 如何使用

1. 打开 composer，选择一个还原图或混合图。
2. 从下方库添加算子。点击它的输入，或在检查器选择上游；点击输出后再点击目标输入即可连接，也支持拖动。
3. 需要插入某条链时，先将新算子接到上游，再将下游改接新算子的输出。
4. 在检查器调整参数。想让工作室使用者调某一项，点击该项的“公开为公式参数”。
5. “导出节点图”保存可编辑布局和数学结构；“导出公式包”保存本项目可加载的完整图和参数依赖。
6. “在工作室打开”加载当前图到本次会话，沿用原材质、灯光、相机与导出能力。要带到另一浏览器，下载公式包，在工作室点击“载入公式包”。

## 首版边界

- 所有自定义混合图标为 heuristic DE，支持连接不代表任意组合都有可靠的表面或保守距离。UBER 的旧 dr 本来也没有完整覆盖实验反馈；没有宣称任意连接是数学上严格的 SDF。
- 一层循环，最多 64 节点、128 条线、32 个公开参数、每轮最多两个球坐标幂；最多 100 次迭代，同时检查设备实际 uniform 预算。
- 图目前是静态参数；没有时钟/相位动画节点。原工作室和旧节点页的 20 秒动画保留。新图中的相位可自由调，独立于原版锁定相位。
- 只有 OrbitState 连接，尚未实现标量/向量独立运算线路、嵌套循环、任意脚本、完整距离场 CSG、GLSL/OSL 外部导出和跨后端材质复现。
- 公式包首版保存形态与公开参数；不封装工作室后来修改的相机/灯光/材质。自定义公式不写入旧预设命名空间；下载公式包用于持久保存。
- 当前错误节点可通过校验定位；底层驱动 shader 编译错误仍显示生成源码诊断，完整源码行→节点定位有待扩展。
- 原公式 kernel 未改；节点实现独立维护，后续公式核心变化需要同时跑参考图 GPU 对照，防止两条实现漂移。
