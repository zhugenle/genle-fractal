# 自适应画质修正 · 2026-10-12

## 问题与修改

旧策略减少光线像素，命中阈值和法线仍按原高分辨率计算，导致小于像素的结构/金属高光欠采样。修改公共预算、主工作室 shader profile 与页面 adapter：实际采样高度控制几何与法线，独立 mappingResolution 保持 Screen 渐变坐标；动态缩小时添加空间边缘抗锯齿，最低 CSS 采样比例从 .35 提高为 .75。它不修改公式、迭代参数、材质颜色或灯光。

录制保留初始 resolve 策略和采样尺寸；完整精度及 PNG 绕过滤波。不累积历史帧。低分辨率动态画面会更柔和；设备无法维持目标帧率时优先保留最低画面密度。

构建与开发监听同时写同一个 .tmp 曾导致 Windows 重命名失败；构建改为跳过未变化文件及使用独立临时文件名，避免相互争用。最终所有生成产物需通过 check:dist。
