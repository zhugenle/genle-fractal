# 自适应清晰度修正

用户反馈上一轮虽然颗粒减少，但图像整体变糊，不能作为最终方案。

## 当前方案

- 空间 resolve 从构建和主页面 draw 链路移除，不创建其 program、纹理或 FBO。
- detailResolution 恢复所选画质的完整参考高度，避免法线取样范围扩大而抹平结构；Screen 坐标仍单独保持 mappingResolution。
- 先自动降低 shader 档位（fine → enhanced → standard），必要时才降像素；主动选择 draft 不自动升级。当前画质为自动策略上限，用户预设不改写。
- 首帧使用约 200 万像素/所选画质/硬件允许的上限；像素下限为 1.25 CSS 比例，受上述上限限制。达到下限后允许帧率下降。
- 低耗时持续后先恢复像素，再恢复档位；恢复档位至少间隔 4 秒。GPU/回退采样包含质量标签，忽略过期档位数据。
- 暂停/PNG 恢复所选完整画质；recordingDimensions.shaderQuality 锁定录制档位。状态栏显示动态降档，中英说明同步。

## 验证

预算模拟覆盖优先降档、保持像素密度、清晰度下限、慢恢复、主动 draft、完整 PNG/暂停与硬件限制；源码/构建检查通过。固定 .25 相位与参考相机比较了旧平滑画面和当前最低标准降档：当前边缘、金属细纹更清晰；画面阴影/受限反射可能随档位改变。这些策略不承诺所有设备维持 30fps 或完全消除细碎高光。

本地浏览器确认 shader 编译与动态档位显示；降档后 PNG 恢复完整尺寸；LAN 入口正常加载。未修改公式、节点兼容 profile、用户材质参数或发布。上一份 adaptive-image-quality.md 保留为被否定方案的历史记录，本说明描述当前实现。
